# FairShare

**Split expenses, not friendships.**

An offline-first expense-sharing app for roommates, friends, couples, and group trips. Built with Flutter, Drift (SQLite), and Riverpod. No accounts, no servers, no telemetry.

> V1 is under construction. See the [V1 milestone](https://github.com/mateoosoriodelhonte/fairshare/milestone/1) for progress.
